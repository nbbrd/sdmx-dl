Automate your workflow by integrating sdmx-dl into your own applications.

- [Use in batch file]({{< relref "/orchestration/use-in-batch-file" >}}) - Automate repeated CLI calls from a Windows `.bat` script.
- [Use in R]({{< relref "/orchestration/use-in-r" >}}) - Call the CLI or REST endpoint from R and load the results as data frames.
- [Use in Excel]({{< relref "/orchestration/use-in-excel" >}}) - Import CSV files or connect Power Query directly to the REST endpoint.
- [Use in Jupyter]({{< relref "/orchestration/use-in-jupyter" >}}) - Fetch data in Python notebooks with subprocess or HTTP, reshape with pandas.
- [Use in jbang script]({{< relref "/orchestration/use-in-jbang" >}}) - Single-file Java/Kotlin scripts with zero project setup.
